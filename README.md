# PHP CRUD Application

## Overview

This project is a simple and responsive CRUD (Create, Read, Update, Delete) application built using PHP, MySQL, PDO, HTML, and CSS. It allows users to manage records through a user-friendly interface while demonstrating core database operations and backend development concepts.

## Features

* Create new user records
* View all users in a table
* Update existing user information
* Delete user records
* MySQL database integration
* PDO prepared statements for secure queries
* Responsive and clean user interface
* Form validation and error handling

## Technologies Used

* PHP
* MySQL
* PDO
* HTML5
* CSS3

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/php-crud-app.git
   ```

2. Move the project folder to:

   ```text
   C:\xampp\htdocs\
   ```

3. Create a MySQL database:

   ```sql
   CREATE DATABASE crud_app;
   ```

4. Import the provided `database.sql` file.

5. Update database credentials in `db.php` if required.

6. Start Apache and MySQL from XAMPP.

7. Open the application:

   ```text
   http://localhost/php-crud-app
   ```
